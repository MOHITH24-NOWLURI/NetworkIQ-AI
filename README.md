# NetworkIQ AI

## Overview

NetworkIQ AI is a Multi-Agent AI-powered inventory optimization system designed to improve stock placement across retail fulfillment networks.

The system analyzes historical sales and inventory data to identify high-demand products, detect low-stock situations, and recommend inventory transfers between warehouses.

## Features

- Demand Analysis Agent
- Inventory Monitoring Agent
- Transfer Recommendation Agent
- Cost-aware Inventory Decisions
- Explainable AI Recommendations
- FastAPI REST APIs
- Retail Supply Chain Dashboard (In Progress)

## Tech Stack
